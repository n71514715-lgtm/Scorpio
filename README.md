# Scorpio
Xbox One Translation Layer for Windows PC

## What is Scorpio?
Scorpio is an Xbox One translation layer similar to how 
Proton works for Linux — translating Xbox One software 
to run natively on Windows PCs.

## Current Status
v0.0.1 - PE file detection working

## Goals
- Load and parse Xbox One game files
- Translate Xbox One API calls to Windows equivalents  
- Eventually run commercial Xbox One games on PC
